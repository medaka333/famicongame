# famicongame

ファミコン風 縦スクロールシューティング（Godot 4.x / GDScript）。

- 解像度 256×240・NES 配色・ドット絵。参考: **スターソルジャー** + **ツインビー**。
- 操作: キーボード（将来ファミコンパッド USB-HID 対応）。
- 詳細設計: [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)

## 起動（M0 動作確認）

1. [Godot 4.3+](https://godotengine.org/) をインストール。
2. このフォルダの `project.godot` を Godot で開く。
3. F5（実行）→ 256×240 が整数スケールで表示されれば **M0 OK**。

## 操作（デフォルト）

| アクション | キーボード | ファミコンパッド(暫定) |
|---|---|---|
| 移動 | 矢印 / WASD | 十字キー |
| ショット | Z | B |
| 特殊（将来: 潜行） | X | A |
| ポーズ | Esc | Start |

> ファミコンパッド（USB-HID アダプタ）はボタン番号が機種依存。M6 のリマップ画面で確定させる。
